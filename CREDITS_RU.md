# Авторство и ресурсы

Tiny Bunny / «Зайчик», оригинальные персонажи, сценарий, музыка, звуки и голоса принадлежат правообладателям оригинальной игры. Проект не является официальным продолжением и не распространяет их игровые архивы или executable.

«Альтернативный взгляд» — некоммерческий пользовательский мод. Реализация, собственные тексты и режиссёрская проверка выполнены с помощью Codex. Новые художественные кадры созданы с помощью ImageGen. Эти иллюстрации проверены в сценах; приведённые здесь два кадра скопированы из текущего релиза без изменений. Схема установки создана отдельно для гайда.

Новая озвучка в первой версии отсутствует. Исходные сцены сохраняют звук установленной оригинальной игры.

Глобальная лицензия на оригинальную игру и её материалы этим репозиторием не предоставляется.
